# Лабораторная работа 2. Классы и инкапсуляция

## BankAccount
- Баланс не может быть отрицательным
- Пополнение и списание выполняются на положительную сумму
- Нельзя списать больше средств, чем есть на счёте

## ProjectTask
- ID и название не могут быть null или пустыми
- Статус не может быть null
- Трудоёмкость не может быть отрицательной
- Статус изменяется через changeStatus()
- Трудоёмкость увеличивается только на положительное число часов
